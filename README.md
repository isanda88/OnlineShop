# 🛒 Online Store Management System

## 📖 Overview

This project was developed in **C#** as part of an Object-Oriented Programming course.

The application simulates a simple online store where users can browse products, add them to a shopping cart, calculate the total price, place orders, and generate invoices.

Product information is stored in an **XML** file, making it easy to organize and manage the available items.

---

## 🚀 Features

- Browse products by category
- Food and non-food product categories
- Add products to the shopping cart
- Remove products from the cart
- Calculate the total order price
- Place an order
- Generate a unique order file
- Generate and preview an invoice
- Display available stock
- Update stock after an order is placed

---

## 🛠️ Technologies Used

- C#
- Windows Forms
- XML
- LINQ to XML
- .NET Framework

---

## 📦 Product Management

Each product contains information such as:

- Product name
- Price
- Quantity
- Description
- Unique identification code
- Expiration date (for food products)

Products are organized into categories such as:

- Fruits
- Vegetables
- Dairy
- Bakery
- Oils
- Clothing
- Footwear
- Detergents
- Stationery
- Bed linens

---

## 🧾 Order Processing

The application allows users to:

- Select multiple products
- Calculate the total price
- Place an order
- Automatically decrease the available stock
- Generate a text file containing the order details

---

## 🖨️ Invoice Generation

After placing an order, the application can generate an invoice that includes:

- Supplier information
- Customer information
- Purchased products
- VAT calculation
- Total amount
- Print preview before printing
